# Project Overview

VietLingua is an AI-powered Vietnamese language learning mobile application designed to help users improve pronunciation and conversational fluency through interactive speaking practice.
This application combines speech-to-text transcription with LLM-based evaluation to provide personalized feedback on users' spoken Vietnamese.
This application was developed to provide users with an interactive way to practice Vietnamese speaking skills and receive immediate feedback without relying solely on traditional memorization or written exercises.

# Key Features

- User registration and authentication using JSON Web Tokens
- Interactive Vietnamese speaking practice
- Speech-to-text transcription using Whisper
- LLM-powered evaluation of spoken responses
- AI-generated pronunciation and language feedback
- Difficulty-based practice sentence selection
- Redis caching for frequently accessed data
- PostgreSQL database for persistent application data
- RESTful API built with Spring Boot
- Dockerized backend infrastructure

# System Architecture

VietLingua uses a client-server architecture. The Flutter mobile application communicates with a Spring Boot REST API. The backend is responsible for authentication, business logic, data persistence, caching, and communication with external services.

<img width="403" height="872" alt="systemarch" src="https://github.com/user-attachments/assets/f4ba671c-66ed-4822-a6f1-24b8491e7ef7" />


When a user completes a speaking exercise, the Flutter application sends the recorded audio to the Spring Boot backend.
The backend processes the audio through a STT service to generate a transcription and then sends the transcription and expected sentence to an LLM for evaluation.
The resulting feedback is returned to the Flutter application and displayed to the user.

# Infrastructure & Deployment

VietLingua uses Docker Compose to containerize and manage the application's backend infrastructure during development and deployment
The Spring Boot backend, PostgreSQL database, and Redis cache run as separate services within the Docker environment.

The Spring Boot application communicates with PostgreSQL for persistent data storage and Redis for caching.
Environment variables are used to configure sensitive credentials and specific settings without storing secrets in the repository.

# Database Design

VietLingua uses PostgreSQL as its primary relational database for storing application data. The database manages user accounts, practice content, practice sessions, and evaluation results generated by the LLM.

The database is structured around the relationship between users and their practice sessions. Each practice session is associated with a practice sentence and contains the user's submitted response and corresponding evaluation data.


# Application Decisions

### Why PostgreSQL?
PostgreSQL was selected as the primary database because the application contains structured relationships between users, practice sessions, sentences, and evaluation results. It is important to track the user's progress in order to create
a curated lesson plan based on the user's experience level.

### Why Redis?
Redis is used to cache frequently accessed practice data and reduce unnecessary database queries. I ran into a problem early on where the LLM would only generate the same sentence over and over again. My solution to this was to store the
last 50 or so sentences in the Redis cache and tell the LLM to generate a sentence that is not one of the stored sentence.

### Why Whisper and OpenAI?
Whisper provides speech-to-text transcription, allowing the application to convert spoken Vietnamese into text for analysis. OpenAI API is then used to evaluate the 
transcription and generate structured feedback for the user. I kept both of these services open-ended so that I can experiment with other services. I have looked into STT services such as Soniox and ElevenLabs, but there are many factors that go into deciding which service to use. 

### Why Exclusively Vietnamese?
Being a child of first-generation Vietnamese immigrants, I grew up not fully understanding nor fully being capable of speaking Vietnamese. This experience is not exclusive to me; I have found that a large percentage of children to Vietnamese refugees also have trouble with speaking Vietnamese and finding the proper resources to do so.
A few years ago, I took it upon myself to learn Vietnamese by using resources such as YouTube and Duolingo. After learning that there are many like me who struggle to learn Vietnamese, I had the idea of using AI tools to generate a lesson plan based on the user's preexisting experience of Vietnamese.
